# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/farisneendoor/Devops_Scripting-.git
```

Move into the project directory:

```bash
cd Devops_Scripting-
```

Give execution permission:

```bash
chmod +x *.sh
```

Run a script:

```bash
./list-users.sh
```
